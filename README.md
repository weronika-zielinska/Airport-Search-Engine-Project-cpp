# Airport Search System – C++

## Project Overview

The Airport Search System is a menu-driven C++ application developed as part of my Software Engineering degree at Nottingham Trent University.

The program allows users to search, manage and analyse airport data through a command-line interface. It provides a range of search, filtering and sorting options to help users explore airport information efficiently.

## Features

### Main Menu
- Search for airports by country, name or IATA code.
- Display all available airport records.
- Count airports by type.
- Add new airport records.
- Delete airports by airport type.
- Save changes to a CSV file.

### Advanced Features
- Sort airports alphabetically by name or country.
- Filter airports by type and sort the results alphabetically.
- Sort airports by elevation, from lowest to highest.
- Identify airports with the highest and lowest elevations.
- Find airports with missing IATA codes.
- Display airports by municipality.
- List unique airport types.
- Count airports by country.

## Technologies and Concepts

- **Language:** C++
- **Data handling:** CSV files
- **Code organisation:** Separate header files and source files
- **Programming concepts:** Functions, conditional logic, loops, data processing, searching, sorting and filtering.

## Learning Outcomes

This project helped me develop my C++ programming skills and practise working with structured data. It also gave me experience in designing menu-driven applications, implementing different data-processing operations and organising code across multiple files.

## How to Run

1. Clone or download this repository.
2. Open the project in a compatible C++ development environment, such as Visual Studio.
3. Ensure the required source files, header files and airport data file are included.
4. Build and run the application.
5. Follow the on-screen menu instructions to explore the available features.
